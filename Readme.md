## 🧠 Problem-Solving Approach

For every problem, I follow this process:

Understand the Problem
        ↓
Identify the Pattern
        ↓
Think of a Brute Force Approach
        ↓
Optimize the Solution
        ↓
Implement the Code
        ↓
Test Edge Cases
        ↓
Analyze Time Complexity
        ↓
Analyze Space Complexity
        ↓
Commit to GitHub

The goal is not only to get an accepted solution but also to understand why the solution works.
